# ALLINO FOODS & RESTAURANTS

**Fresh Food. Local Kitchens. One Platform.**

Premium animated Next.js food-tech experience with:
- Public marketplace landing page
- 3D-style food hero and card interactions
- Framer Motion shared animation system
- Reduced-motion accessibility
- Dark premium SaaS CRM dashboard
- Responsive layouts and GPU-friendly transforms

## Run

```bash
npm install
npm run dev
```

Routes:
- `/` public website
- `/crm` CRM dashboard


## Living background system

The production site uses the reusable `components/background/AnimatedBackground.tsx` system with responsive organic gradients, particles, leaves, parallax, reduced-motion support, and CRM/dark variants.
